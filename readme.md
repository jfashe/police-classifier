# Police Car Classifier Project
### By Joshua Fashe - Started September 15, 2026

I'm training a computer-vision, machine learning model that classifies cop cars and civillian cars just by looking at an image. I'll be training it with phone and dashcam pictures of cop cars seen all throughout Houston, TX, in a variety of conditions.  The end goal is to run it real-time on a dashcam, so that it can automatically flag when a police car is nearby.

I've vibecoded a project before, but I'll be building this classifier model from the ground up. I'll also be documenting my journey on linkedin and youtube. 

The purpose of this project is to build something meaningful with my ML skills. I'm a computer engineering major at the University of Houston, and I'm taking Andrew Ng's Machine Learning Specialization course, and FreeCodeCamp's Data Science with Python course. The CS part of my degree doesn't go too in-depth past data structures and algorithms. Thanks for reading!
